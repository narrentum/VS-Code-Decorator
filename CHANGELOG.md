# Change Log

All notable changes to the "Decorator" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [Unreleased]

## [1.3.0]

- Moved full-document regex analysis into the native .NET helper process.
- Added safe `csharpAttributeNames` scanner for C# attribute-name highlighting.
- Added compact per-rule `settings` format with aliases: `on`, `noStr`, `noComm`, `bg`, `decor`, and `groups`.
- Added diagnostics in the `Code Decorator` Output Channel for invalid compact settings entries.
